# ICWS - Integrated Consumer Water System

A web-based Utility Billing and Monitoring System developed as a capstone project for water service providers.

## Features

- Consumer account management
- Meter reading management
- Automated billing generation
- SMS notification support
- Mobile Utility Reader application
- Consumer Mobile Portal
- Billing history and consumption analytics
- Administrative reporting dashboard

## Technology Stack

- PHP
- MySQL
- JavaScript
- HTML/CSS

## Components

### Utility Billing System
Web-based administration and billing management portal.

### Mobile Utility Reader
Used by utility personnel to record meter readings and transmit billing data.

### Mobile Consumer Portal
Allows consumers to view billing history and consumption records.

## Database

Import the included SQL database into MySQL before running the application.
